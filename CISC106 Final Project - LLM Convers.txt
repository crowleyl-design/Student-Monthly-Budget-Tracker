User: I am coding my routes in Thonny now. When I use a TextBox to get the cost or budget from the user, Drafter passes it into my route function as a string. How do I safely convert that string into a float using basic CISC106 string methods so my program doesn't crash if someone types letters or leaves it blank?

AI: Since TextBox inputs always pass strings into your route parameters, you can write a small helper function using the .isdigit() string method before calling float():

def string_to_float(text: str, default_number: float) -> float:
    """Converts a string of digits to a float or returns the default."""
    if text.isdigit():
        return float(text)
    else:
        return default_number

If the user types a valid whole number like "50", text.isdigit() is True and it returns 50.0. If they leave it blank or type letters, it returns your default_number so your site doesn't crash.

User: I got an error when clicking my "View Expenses" button from the Home page because view_expenses expects both state and category_filter: str from the SelectBox, which isn't on the Home page. How do I fix that?

AI: In Drafter, a button on the Home page can only pass parameters from inputs that exist on the Home page. Since the SelectBox("category_filter", ...) is on the Expense List page and not the Home page, you can create a simple route for your Home page button that only takes state: State and passes state.selected_category to view_expenses:

@route
def show_all_expenses(state: State) -> Page:
    """Opens the expense list page with the current category filter."""
    return view_expenses(state, state.selected_category)

Then use Button("View Expenses", show_all_expenses) on your index page, and keep Button("Apply Filter", view_expenses) on your expense list page.
